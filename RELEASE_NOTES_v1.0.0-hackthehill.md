# CalmID v1.0.0-hackthehill

Stable Hack the Hill release.

## Highlights

- Presage biometric-assisted scan flow
- Front-camera framing mirror
- Live Presage positioning feedback
- Pulse / breathing-related signals when available
- 4-1-6 guided breathing animation
- Meditation-only mode without biometrics
- French / English local TTS guidance
- ElevenLabs live voice coach
- Local voice fallback when cloud voice is unavailable
- Familiar voice concept presented as a future feature
- Polished Android UI designed for a no-scroll breathing experience

## Known Limitations

- Biometric measurements can be intermittent depending on framing, lighting, motion, and device conditions.
- Familiar voice cloning / upload is not implemented in this release.
- CalmID is a wellness demonstration, not a medical diagnostic tool.

## Hackathon Scope

Auth0 authentication was intentionally removed from the final hackathon scope to prioritize the core biometric + breathing + voice experience.
